Python Student Management System

About the Project

This is a beginner-friendly Python project designed to manage student records through a simple menu-driven program.

Technologies Used

- Python
- Lists and dictionaries
- Functions and conditional statements

Features

- Add student details
- View student records
- Search for a student
- Update student details
- Delete student records

How to Run

1. Install Python.
2. Download or clone this repository.
3. Run "student_management.py".

Purpose

This project helped me practise Python programming and understand basic data management.
